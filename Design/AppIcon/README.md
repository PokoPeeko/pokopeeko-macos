# PokoPeeko icon

`Concepts/02-rabbit-laptop-apple-v2.png` is the user-selected transparent PNG master used by the macOS AppIcon asset catalog. It depicts a rabbit behind an upright laptop with a centered Apple logo. `pokopeeko-logo.png` is the earlier, unselected rabbit/chat concept. This is raster artwork, not an SVG/PDF vector source. Built-in image generation was used with the user's original rabbit illustration as a visual reference.

AppIcon PNGs are resized from the selected master, preserving alpha. The selected variant prompt is in `Concepts/02-rabbit-laptop-apple-v2.md`; the prompt below describes the earlier rabbit/chat concept.

## Generation prompt

Use case: logo-brand. Create one simplified production macOS app icon for PokoPeeko, using the provided image as visual reference only. Keep its friendly white rabbit and lavender/indigo identity, but distill it into a bold flat geometric logo: one white rabbit-head silhouette with two short rounded upright ears, two small dark purple eyes, and one tiny friendly smile, subtly integrated into a single chat-bubble silhouette with a small tail. A centered white rabbit-chat symbol on one muted periwinkle purple rounded-square tile, with generous consistent inset (tile occupies about 82% of the canvas) and genuinely transparent pixels outside the tile, including the four corners. Shape must be unmistakable at 32 px. Almost flat vector-style finish, restrained minimal gradient only on purple tile, no texture or glossy shading. No laptop, Apple logo, code symbols, music notes, secondary bubbles, hands, cheek decorations, text, letters, watermark, or mockup. Single square icon composition, not a presentation sheet.
