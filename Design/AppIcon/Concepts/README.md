# App icon concepts

Five alternatives generated with the built-in image generation tool using the user's original icon as product context. These are raster PNG concept previews, not vector originals. They have not replaced the app's current icon; selection and final edge cleanup are separate from producing the concepts.

1. `01-laptop-chat.png`: laptop and plain chat badge.
2. `02-rabbit-laptop.png`: rabbit peeking over a laptop.
3. `03-presence-window.png`: friend profiles in a desktop window.
4. `04-focus-orbit.png`: overlapping activity windows.
5. `05-rabbit-ear-laptop.png`: rabbit-ear laptop outline.
