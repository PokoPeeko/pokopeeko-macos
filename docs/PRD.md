# PokoPeeko — PRD

## 1. 프로젝트 개요

PokoPeeko는 친구들이 현재 사용 중인 macOS 애플리케이션과 사용 시간을 실시간으로 공유하는 메뉴바 애플리케이션이다.

사용자는 메뉴바에서 친구들의 활동 상태를 확인하고, 메인 앱에서 자신의 활동 현황과 친구를 관리할 수 있다.

## 2. 주요 기능

### 2.1 인증 및 프로필

- Sign in with Apple 및 Firebase 기반 로그인
- 기존 사용자와 신규 사용자 구분
- 신규 사용자 프로필 설정
- 프로필 조회 및 수정
- 로그아웃 및 계정 탈퇴

### 2.2 앱 활동 추적

- 현재 포커스된 macOS 애플리케이션을 감지한다.
- 포커스 변경 및 앱 종료 시 발생한 이벤트를 서버에 전달한다.
- 이벤트에는 앱 식별자와 발생 시각을 포함한다.
- 포커스가 해제된 앱은 사용 시간 측정을 일시 중지한다.
- 다시 포커스되면 기존 누적 시간부터 측정을 재개한다.
- 앱 종료 시 해당 앱의 활동 기록을 마감한다.
- 사용 시간은 앱별로 누적하여 관리한다.

### 2.3 실시간 활동 공유

- 친구의 온라인 및 오프라인 상태를 표시한다.
- 친구가 현재 사용 중인 앱과 사용 시간을 표시한다.
- 서버에서 전달받은 활동 상태와 시간 정보를 바탕으로 클라이언트가 표시 시간을 갱신한다.
- 앱 실행 및 서버 재연결 시 현재 상태와 누적 사용 시간을 복원한다.

### 2.4 친구 관리

- 친구 추가 및 삭제
- 친구 목록 조회

### 2.5 메뉴바

- 메뉴바 아이콘을 클릭하면 친구 활동 목록을 표시한다.
- 친구별 프로필 이미지, 이름, 온라인 상태를 표시한다.
- 현재 사용 중인 앱과 사용 시간을 표시한다.
- 메인 앱 및 설정 화면으로 이동할 수 있다.

### 2.6 메인 앱

사이드바를 통해 다음 화면으로 이동한다.

- **Dashboard:** 자신의 활동 현황 요약
- **Friends:** 친구 목록 및 관리
- **Apps:** 앱별 사용 현황 조회
- **Profile:** 프로필 및 계정 관리
- **Settings:** 애플리케이션 설정
- Info: 앱 정보
- Feedback: 사용자 피드백 수집

각 화면의 세부 기능은 개발 과정에서 구체화한다.

## 3. 개발 범위 및 우선순위

1. 메인 앱 및 메뉴바 기본 UI
2. 앱 활동 감지 및 사용 시간 측정
3. 서버 연동 및 실시간 활동 공유
4. 친구 관리, 프로필 및 설정 기능
5. 전체 기능 검증 및 개선

인증 기능은 기존 구현을 기반으로 변경된 백엔드 API 명세 확인 후 마무리한다.

### 3.1 UI 구현 단계

- 메인 앱의 전체 사이드바와 각 화면의 기본 UI를 구성한다.
- 메뉴바 팝오버는 친구 목록, 온라인 필터, 메인 앱·친구·설정 화면 이동을 제공한다.
- 실제 데이터 연결 전에는 빈 상태를 표시하고, 명시적으로 켠 샘플 데이터로 UI를 확인할 수 있다.
- 친구·앱 검색, 온라인 필터, 앱 정렬은 현재 표시 데이터에 적용한다.
- 테마 설정은 로컬에 저장하고 메인 앱과 팝오버에 함께 적용한다.
- 피드백 화면은 초안 작성과 복사만 제공한다. 전송 기능은 미연동 상태로 안내한다.
- 프로필 조회·수정과 친구 추가·삭제는 미연동 상태로 안내한다.
- Debug 빌드에서만 로그인·세션을 변경하지 않는 별도 UI 미리보기 창을 제공한다.
- 앱 활동 감지, 사용 시간 측정 및 서버 연동은 이 단계에 포함하지 않는다.

진행 순서는 UI 구현 및 첫 커밋·푸시, 인증 완성 및 별도 커밋·푸시, 이후 실제 기능 연동으로 한다.

## 4. 향후 확장

음악 서비스 연동 등 추가 기능을 고려할 수 있으나 현재 개발 범위에는 포함하지 않는다.
