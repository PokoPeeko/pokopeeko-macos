# PokoPeeko — PRD

## 1. 프로젝트 개요

PokoPeeko는 친구들이 현재 사용 중인 macOS 애플리케이션과 사용 시간을 실시간으로 공유하는 메뉴바 애플리케이션이다.

사용자는 메뉴바에서 친구들의 활동 상태를 확인하고, 메인 앱에서 자신의 활동 현황과 친구를 관리할 수 있다.

## 2. 주요 기능

### 2.1 인증 및 프로필

- Sign in with Apple 및 Firebase 기반 로그인
- 기존 사용자와 신규 사용자 구분
- 목표 계약은 서버의 `needsProfileSetup`이 true이면 닉네임 필수·사진 선택 프로필 설정, false이면 메인 앱 진입이다. 현재 재로그인 문제 진단을 위해 사용자 요청으로 반대로 해석하는 임시 클라이언트 처리를 적용한다.
- 설정 성공과 세션 저장 완료 후에만 앱 진입, 설정 중 재실행 시 설정 화면 복원
- 프로필 조회 및 수정
- 프로필 화면에서 사진을 다시 선택하고 업로드할 수 있다. 사진만 변경할 때 닉네임은 변경하지 않는다.
- 프로필 화면에서 닉네임을 변경할 수 있다. 공백 없는 1~10자로 제한하며 사진과 사용자 UUID는 유지한다. 저장 중 중복 요청을 막고 서버 성공 및 로컬 저장 후 표시 이름을 갱신한다.
- 로그아웃 및 계정 탈퇴

### 2.2 앱 활동 추적

- 현재 포커스된 macOS 애플리케이션을 감지한다.
- 포커스 변경 및 앱 종료 시 발생한 이벤트를 서버에 전달한다.
- 포커스 이벤트에는 새로 활성화된 앱의 식별 정보를 포함하고 서버가 수신 시각을 기준으로 시간을 관리한다. 앱 전환 시 이전 앱의 포커스 해제는 서버가 함께 처리한다.
- 포커스가 해제된 앱은 사용 시간 측정을 일시 중지한다.
- 다시 포커스되면 기존 누적 시간부터 측정을 재개한다.
- 앱 종료 시 해당 앱의 활동 기록을 마감한다.
- 앱을 다시 실행하면 새 기록을 0부터 시작한다. PokoPeeko보다 먼저 실행된 앱은 감지 시작 시점부터 측정하며 이전 포커스 시간을 추정하지 않는다.
- 대상 앱의 한 실행에는 하나의 실행 ID를 유지한다. 포커스 전환 후 복귀는 같은 ID로 재개하고, 대상 앱 종료 후 재실행은 새 ID로 구분한다. 송수신 API의 구체적인 필드 구성은 별도로 확정한다.
- 사용 시간은 앱별로 누적하여 관리한다.

### 2.2.1 앱 목록 관리

- 앱 목록에서 감지 허용 여부와 앱 내 노출 여부를 각각 선택한다.
- 감지 관리 UI는 일반 목록의 ‘차단’ 버튼과 차단 목록의 ‘차단 해제’ 버튼으로 제공한다. 앱 내 노출 여부는 별도 토글로 유지한다.
- 감지 비활성화는 앱 내 차단으로 취급하며, 해당 앱이 자동 감지되어도 목록에 다시 등록하지 않는다.
- 차단한 앱은 별도 탭에서 조회하고 차단을 해제할 수 있다. 차단 해제 시 일반 앱 목록으로 돌아간다.
- 노출 비활성화는 목록을 유지하며 감지된 활동의 표시를 숨기는 설정이다.
- 삭제는 관리 목록에서만 제거하며 설치된 macOS 앱을 삭제하거나 감지를 차단하지 않는다. 차단하지 않은 앱은 다음 자동 감지 시 재등록될 수 있다. 차단 정보는 일반 목록 삭제와 별도로 유지한다.
- 자동 감지되지 않는 앱은 직접 추가할 수 있다.
- `.app` 파일 선택 또는 앱 이름·번들 ID 입력으로 직접 추가한다.
- 로컬 앱 목록·차단·노출 설정과 직접 추가 정보는 재실행 후에도 유지한다.
- 시작 시 실행 중인 일반 앱을 등록하고, 이후 앱 실행·활성화·종료를 감지한다. 백그라운드 보조 프로세스와 PokoPeeko 자신은 제외한다.
- 앱 목록 및 친구 활동 행은 로컬에 설치된 앱의 실제 아이콘을 사용한다. 로컬에서 찾지 못한 앱은 기본 아이콘으로 표시한다.

### 2.3 실시간 활동 공유

- 친구의 온라인 및 오프라인 상태를 표시한다.
- 친구가 현재 사용 중인 앱과 사용 시간을 표시한다.
- 서버에서 전달받은 활동 상태와 시간 정보를 바탕으로 클라이언트가 표시 시간을 갱신한다.
- 앱 실행 및 서버 재연결 시 현재 상태와 누적 사용 시간을 복원한다.

### 2.4 친구 관리

- 친구 추가 및 삭제
- 친구 목록 조회
- 친구 행을 눌러 프로필 상세 조회 및 새로고침
- 프로필과 아바타는 클라이언트에 캐시하고 새로고침 중에도 기존 내용을 유지해 화면 깜빡임을 줄인다. 서버 응답으로 갱신하고 계정별 프로필 캐시와 인증 판단을 구분한다.
- 사용자 이름으로 검색하고 선택한 결과의 UUID로 친구 요청 보내기
- 받은·보낸 요청 조회, 수락·거절·취소
- 요청 처리 후 친구·요청 목록 갱신, 오류·중복 조작 처리

### 2.4.1 다음 구현 범위

- Mac의 Apple Music·Spotify 데스크톱 앱에서 재생 중인 곡·가수·재생 여부를 감지하는 방식으로 음악 연동을 시작한다. 다른 기기의 재생 상태를 읽는 계정 연동은 이후 범위다.
- 브라우저 작업 설명은 사이트명을 기본으로 공유하고, 페이지 제목은 사용자가 선택한 경우에만 공유한다. 시크릿 창·제외 사이트는 상세 공유에서 제외하며 URL 경로·쿼리를 서버로 전송하지 않는다. 창의 공개 여부를 판별할 수 없으면 상세 표시를 생략한다.
- 시간은 날짜별 초기화 대신 앱 실행·종료에 따른 실행 세션 단위로 설계한다. 서버가 시간을 누적하고 클라이언트가 표시하는 원칙은 유지한다.
- 음악 연동과 사용 시간 누적을 우선한다. 친구 삭제는 상세 sheet에서 제공하고 계정 탈퇴·피드백 전송은 보류한다. 사용자 검색은 추가된 `/api/user/search` 명세로 연결한다.
- 강제 종료·재연결 복원·다중 기기·이벤트 순서 등 후속 안정성 항목은 [별도 문서](FOLLOW_UP_STABILITY.md)에서 관리하고 정상 시간 공유·음악 연동을 우선 구현한다.

### 2.5 메뉴바

- 메뉴바 아이콘을 클릭하면 기본적으로 온라인 친구만 표시하고, 사용자가 선택하면 오프라인 친구도 함께 표시한다.
- 이름 옆 공간은 노래 제목과 가수 이름을 표시하는 데 사용하며, 음악 정보가 없으면 비워둔다.
- 팝오버의 이동 버튼은 해당 메인 앱 창을 열고 활성화한다.
- 친구별 프로필 이미지, 이름, 온라인 상태를 표시한다.
- 현재 사용 중인 앱과 사용 시간을 표시한다.
- 메인 앱 및 설정 화면으로 이동할 수 있다.

### 2.6 메인 앱

사이드바를 통해 다음 화면으로 이동한다.

- **Dashboard:** 자신의 활동 현황 요약
- **Friends:** 친구 목록 및 관리
- **Apps:** 앱별 사용 현황 조회
- **Profile:** 프로필 및 계정 관리
- **Settings:** 애플리케이션 설정
- Info: 앱 정보
- Feedback: 사용자 피드백 수집

각 화면의 세부 기능은 개발 과정에서 구체화한다.

## 3. 개발 범위 및 우선순위

1. 메인 앱 및 메뉴바 기본 UI
2. 앱 활동 감지 및 사용 시간 측정
3. 서버 연동 및 실시간 활동 공유
4. 친구 관리, 프로필 및 설정 기능
5. 전체 기능 검증 및 개선

확인한 인증 API를 기준으로 로그인·최초 프로필 설정·로그아웃을 연결한다. 프로필 조회와 앱 시작 시 세션 확인, 친구 요청 처리를 확인된 API로 연결한다.

### 3.1 UI 구현 단계

대시보드의 수정 중인 UI 시안은 상단 프로필, 친구·앱 목록 2열, 음악 연동·앱 설정 2열, 하단 앱 정보 카드로 구성한다. 각 패널은 제목·여백·chevron을 포함한 헤더 전체를 클릭해 해당 화면으로 이동한다. 음악 패널은 선택한 Mac 음악 앱의 현재 곡·가수와 로컬 공유 상태를 표시한다.

현재 수정 중인 UI 시안(확정 요구사항 아님)은 사이드바 섹션 없이 대시보드, 친구, 앱 목록, 음악 연동, 프로필, 설정, 정보 순서로 배치하고, 피드백은 사이드바 최하단의 작은 버튼으로 제공한다. 음악 연동은 Apple Music·Spotify 데스크톱 앱 감지를 제공한다.

- 메인 앱의 전체 사이드바와 각 화면의 기본 UI를 구성한다.
- 메뉴바 팝오버는 온라인 친구 기본 표시, 오프라인 포함 옵션, 메인 앱·친구 추가·설정 화면 이동과 창 활성화를 제공한다.
- 샘플 데이터를 제공하지 않는다. 앱 목록은 실제 로컬 감지 결과를 사용하며 친구·요청·프로필 정보는 실제 API 응답을 사용한다. 실시간 앱 상태는 Socket.IO 이벤트로 반영하며, 연결 실패 시 확인 불가로 표시한다. 최초 프로필 설정 응답은 화면에 반영한다.
- 친구·앱 검색, 온라인 필터, 앱 정렬은 현재 표시 데이터에 적용한다.
- 테마 설정은 로컬에 저장하고 메인 앱과 팝오버에 함께 적용한다.
- 로그인 시 자동 실행은 macOS 로그인 항목으로 등록·해제하고 실제 승인 상태를 표시한다. 추가 승인이 필요하면 시스템 설정으로 이동하는 버튼을 제공한다.
- 설정에서 앱 활동 공유를 일시 중지·재개하고 메뉴바의 오프라인 친구 포함 여부를 저장한다.
- 정상 실시간 연결 인디케이터·개발용 연결 오류 영역은 화면에서 제거하고, 연결·오류 상태를 토큰이나 사용자 활동 내용 없이 콘솔에 기록한다.
- 메인 앱과 팝오버의 공통 강조색은 차분한 블루 톤을 사용하고, 라이트·다크 모드에 맞춰 밝기를 조정한다.
- 피드백 화면은 초안 작성과 복사만 제공한다. 전송 기능은 미연동 상태로 안내한다.
- 친구 목록·추가·요청 탭과 받은 요청·보낸 요청 UI를 제공한다. 이름 검색·UUID 대상 선택, 요청 전송·수락·거절·취소를 연결한다. 친구 삭제는 별도 탭 없이 프로필 상세 sheet에서 제공한다.
- 로그인·프로필 설정·메인 화면은 빌드 구성과 관계없이 하나의 창 안에서 전환한다. 메뉴바에서 메인 앱을 열 때에도 같은 창을 활성화한다.
- 앱 활동 감지와 로컬 목록 관리는 연결한다. 현재 앱 이름의 Socket.IO 실시간 공유를 연결한다. 사용 시간 측정·서버 누적 시간 연동은 이후 단계로 남긴다.

UI 정리와 로컬 앱 감지를 먼저 진행하며, 인증 완성과 서버 연동은 API 명세 확인 후 진행한다.

### 3.2 발표용 최소 서버 연동 범위

로그인 → 이름 검색·친구 요청·수락·목록 → 현재 앱 실시간 공유를 연결한다. 로그인 HTTP 500 해결과 Socket.IO 외부 접속 가능 여부는 배포 서버에서 확인해야 한다. 소켓 연결 실패가 친구 REST 기능을 막지는 않는다. 이벤트·타이머·비공개 상태 정책은 [실시간 API](API_PRESENCE.md)를 따른다. 사용 시간은 이후 범위이며, 음악 감지·곡 전송은 추가 구현했다. 재생·일시정지·종료 공유는 음악 API 문서를 따른다.


## 4. 향후 확장

다른 기기의 음악 재생 상태를 읽는 계정 연동 등 추가 기능은 이후 범위로 둔다. Mac 음악 앱 감지·상태 공유는 구현했고 사용 시간 누적은 다음 범위다.

### Mac 음악 감지 구현

- Apple Music·Spotify 중 선택한 앱의 곡·가수·재생 상태를 약 1초 간격으로 로컬 확인한다. 기본 공유는 꺼짐이며 변경 시에만 전송한다.
- 일시정지는 로컬·친구 화면에 pause 표시, 종료·공유 끄기는 음악 숨김으로 처리한다. 긴 곡 제목은 넘치는 경우에만 스크롤한다.
- 서버에는 곡·가수와 PLAYING/PAUSE를 보내고 종료는 별도 음악 삭제 이벤트로 전달한다. 늦은 접속은 최신 저장 상태를 받아 표시한다. 상세 계약과 한계는 [음악 API](API_MUSIC.md)를 따른다.

- 음악 연동 화면은 앱 실행 대기·권한 확인/거부·연결 실패·연결됨을 구분한다. 정상 연결되면 안내 대신 현재 곡 카드, 가능한 앨범 표지와 로컬 재생 진행률을 표시한다. 연결은 됐지만 곡이 없는 경우에는 연결됨과 재생 대기를 표시한다. 표지·진행률은 서버 공유 범위에 포함하지 않는다.

- 음악 감지/공유는 ‘이 Mac의 음악’ 카드 헤더의 switch로 카드 전체를 켜고 끈다. macOS 자동화 권한 요청은 별도 버튼에서만 수행하고, 자동 감지·공유 토글·재시도는 승인 창을 띄우지 않는다.

- 개발용 로컬 진입·단계 안내·프로필 이미지 주소 진단 UI를 제거한다. API 미구현 사유나 내부 UUID는 친구 목록·프로필 상세에 표시하지 않는다. 친구 추가는 이름 검색 결과를 선택하며 UUID는 내부에서만 사용한다.

- 메뉴바 팝오버의 친구들과 같은 목록 맨 위에 내 프로필·현재 공유 대상 앱을 고정하고 이름 옆에 곡/가수를 표시한다. 온라인 필터는 친구에게만 적용해 친구가 없어도 내 행은 표시하고, 누르면 내 프로필로 이동한다.
- 프로필 사진을 클릭하면 사진 선택·미리보기·저장을 제공하는 상세 sheet를 연다. 별도 사진 변경 버튼과 닉네임 변경 sheet는 제거한다. 닉네임은 인라인 필드에서 수정하며 유효하고 기존 값과 다를 때만 ‘변경하기’를 활성화한다. 저장 성공 시 현재 이름을 기준값으로 갱신하고 새로고침은 작성 중인 입력을 유지한다. 프로필 새로고침은 친구 탭과 같은 화살표 아이콘 버튼을 사용한다.

- 로그인·최초 프로필 설정 온보딩은 전체 창과 중앙 폼 카드에 공통 AccentColor의 은은한 그라데이션을 적용한다. 색상 정의와 적용 규칙은 [디자인 규칙](DESIGN.md)에 기록한다.

- 메뉴바 내 행의 ‘나’ 배지를 제거하고 이름과 음악 사이에 `·`를 표시한다. 친구 화면의 ‘온라인만’은 메뉴바의 오프라인 포함과 같은 버튼형 Toggle로 표시한다.
- 메뉴바의 친구 프로필은 같은 호스팅 창 내부 상세 화면으로 표시하고 닫으면 목록으로 돌아간다. 삭제 확인도 내부 UI로 처리해 별도 모달 창의 포커스 이동으로 메뉴바가 닫히는 경로를 제거한다. 메인 앱에서는 기존 프로필 sheet를 유지한다.
- 대시보드 음악 카드에도 음악 연동 화면과 동일한 표지·곡·가수·로컬 재생 진행률을 compact 형태로 표시한다.

- 메뉴바 친구 상세는 같은 창 안의 너비 300pt·최소 높이 380pt의 불투명 카드로 표시하고 카드 내부 스크롤은 사용하지 않는다. 배경 목록을 덮는 전체 화면형 상세는 사용하지 않는다.
- 필터 버튼은 기존 컨트롤과 유사한 모양을 유지하고 활성 상태의 버튼 배경만 강조한다. 텍스트 색은 두 상태에서 동일하다. 설정의 A/B 스타일 선택 항목은 제거한다.

- 팝오버의 친구 프로필은 친구 탭과 같은 상세 컴포넌트·내용·서식을 재사용하고 표시 영역 크기만 줄인다.
